Караоке-фортуна

1. Распакуйте архив целиком в любую папку.
2. Откройте файл index.html двойным щелчком — он откроется в браузере
   (подойдут Chrome, Яндекс Браузер, Safari, Edge).
3. Нажмите «Вращать».

Интернет не нужен. Файлы и папки внутри не переименовывайте и не перемещайте.
Запускать нужно на компьютере; на телефоне из архива не откроется.
